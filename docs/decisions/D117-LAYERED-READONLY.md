# D117 — 按层只读与规范写法

Status: accepted — 2026-09-13（所有者授权；Core 0.10 / toolchain 0.34.0）

## 语义

`readonly` 约束其直接修饰的层。它是编译期的写入权限，不改变对象身份。

- `readonly field: T` 禁止替换该字段，读取结果仍为 `T`。
- `readonly type T:` 将自己的和继承的字段槽位全部设为只读，字段值保留声明类型。
- `readonly T` 对记录的所有字段槽位施加只读视图。
- `readonly List<T>` 禁止替换索引槽位和增删；读取、遍历、回调得到 `T`。
- `readonly Map<K, V>` 禁止更改映射；读取和遍历得到 `K`、`V`。
- `readonly Set<T>` 禁止更改成员集合；读取和遍历得到 `T`。
- `readonly Record<T>` 禁止替换、增加和移除属性；读取属性值仍为 `T`。

| 类型 | 修改容器槽位 | 修改元素的可写字段 |
| --- | --- | --- |
| `List<State>` | 允许 | 允许 |
| `readonly List<State>` | 禁止 | 允许 |
| `List<readonly State>` | 允许 | 禁止 |
| `readonly List<readonly State>` | 禁止 | 禁止 |

如果 `State` 已声明为 `readonly type`，使用处直接写 `State`。额外的
`readonly State` 与它的槽位契约等价。对于全部字段已逐一标记只读的记录也采用
相同的结构兼容规则；泛型应用、导入、别名、可选类型和联合类型保持该规则。

只读字段可持有集合、函数、class 实例、宿主对象或泛型值。容器同样可持有它们。
这些值按自己的声明开放操作。直接的 `readonly Class`、`readonly Promise<T>`、
`readonly` 函数、标量或无约束 `readonly T` 仍无对应的槽位视图，编译器拒绝。

## 赋值、读取与新容器

可变容器可传给接受其只读视图的参数。只读视图不可传给能改写受保护槽位的契约。
记录逐字段检查替换权限和字段值类型；同一记录的声明级只读和视图级只读兼容。

只读集合对声明的元素、键和值类型协变；可变集合保持不变性。比较嵌套类型时保留
其真实写入能力，例如 `readonly List<Narrow>` 不能变为
`readonly List<Wide>`，如果 `Wide` 可以向对象字段写入 `Narrow` 不接受的值。

成员读取、索引、可选链、窄化、解构、展开、集合回调、转换、`copy`、`slice`、
`keys`、`values` 都保留值的声明类型。新建容器拥有新的可写槽位，共享元素保留
原来的权限。`List<readonly State>` 的复制结果仍含只读元素。

运行时 `is` 与模式匹配保留来源的逐层只读权限；验证形状不能恢复槽位写入权限，
也不能扩大现有可写字段接受的值域。递归形状的重复边界保留来源声明契约。

显式的嵌套保护由各层类型组合表达：

```velar
readonly type Position:
    x: number
    y: number

readonly type Snapshot:
    positions: readonly List<Position>
```

`Snapshot` 的字段不能替换，列表不能修改，`Position` 的字段不能替换。

## 诊断与自动修复

- **A20**：没有基类且全部自有字段逐一只读的记录，提升为 `readonly type`；
  `readonly type` 内重复的字段修饰符可移除。有基类时不自动提升普通声明，
  以免增加继承槽位的限制。
- **A21**：已经只读的类型再包同层 `readonly`，移除冗余限定符；适用于别名、
  已解析的记录字段契约和直接重复的限定符。
- 修复保留字段类型内的 `readonly`、泛型参数、导出、注释与可选性。
  字段修饰符和字段值类型的修饰符有不同作用，不能相互替代。
- 使用既有 advisory、编辑器 quick fix 和 `velar fix` 通道。建议不阻止编译。

## 升级与验证

0.34.0 使用本标准。原来依赖隐式深层保护的代码，需要在所保护的嵌套类型上明确
标注只读，或者为数据记录使用 `readonly type`。自动修复只做新标准内等价的化简；
升级时的所有权选择需要根据应用的真实调用和写入点完成。

验证覆盖四种 List 组合、其他集合、记录字段、继承、泛型、跨模块、别名、
方差、复制与展开、回调、运行时身份、格式化、诊断和自动修复闭环。
