## 第 172 条 —— `objectPosition` 改为 `metric`，与它的两个同族对齐

波 Q2 指出的不对称：

| 属性 | 今天的 kind | CSS 语法 |
|---|---|---|
| `backgroundPosition` | `metric` | `<position>` |
| `transformOrigin` | `metric` | `<position>` |
| **`objectPosition`** | **`keyword`** | `<position>` |

**三者语法相同，其中一个的 kind 不同。** Q2 按第 169 条给它发了 22 个关键字
位置格并把长度/百分比记进排除表 —— **但那是在为一个不该存在的分类打补丁。**

**裁决：改为 `metric`，与另两个对齐；随之撤销它的部分排除记录。**

理由：`metric` 分支落地后同时查单位与属性自己的词表（波 P1 修的正是这一点），
所以 `objectPosition = 50%` 与 `objectPosition = "top left"` 都成立 ——
**能力更全，且三个同语法属性回到同一种解释。**

**它停下来问是对的**：改 kind 会变更该属性接受的类型，是语义变更，不是实施细节。

## 第 173 条 —— 不变量要覆盖全部 78 个 keyword 属性，排除记录是交付物

波 Q2 只关了 brief 点名的 26 个。它扫了剩下 52 张**已发布**的词表，
发现**同一族的 A 面（真值被拒）依然存在**：

| 属性 | 拒掉的真值 |
|---|---|
| `touchAction` | `pan-left` / `pan-right` / `pan-up` / `pan-down` / `pinch-zoom` —— **全是常用值** |
| `fontStyle` | `oblique <angle>` |
| `textOverflow` | `<string>` 形式（`text-overflow: "…"`） |
| `cursor` | `url()` 形式 |
| `display` | `list-item` 与双关键字语法 |

**裁决：把不变量做到完备 —— 78 个 keyword 属性逐个复核。**

**但交付物不是「补齐值」，是「排除记录」。** 一个属性发布它语法的子集完全可以，
**前提是那个子集的边界写下来了、并且诊断说得出来**。
今天的问题不是子集太小，是**没有人知道边界在哪**。

### 它正确地没有把一个有意的闭集报成缺陷

`transitionTimingFunction` 缺 `cubic-bezier()` / `steps()` / `linear()` ——
但它派生自 `LOOK_ANIMATION_EASINGS`，而 D49 让 `animate(easing=)` 用的是同一张表。
**Q2 判断这「看着像有意的闭集」，没有当缺陷报。**

**判断正确，且这条区分正是完备化那一波最容易做错的地方**：
把有意的封闭当成缺口去"补齐"，会把 D49 的裁决悄悄推翻。
**完备化的第一步是分清「漏了」与「关了」，不是数值。**

## 第 174 条 —— VEL5038 必须说出合法值是什么

现在的消息是「use one of the closed X keywords」——**不说是哪些。**

**证据是最有说服力的那种：展示自己写出了 12 个假值。**
写展示的是知道设计意图的人，**而他在这条消息面前只能猜。**

**裁决：小词表列全部合法值；大词表给最近拼写建议**
（`nearestLookName` 是现成的）。

这条与本仓一路在拔的是同一族：**一条不说出正确拼写的诊断，不是教学式诊断。**
语言的核心承诺是「每个错误拼写得到一条命名唯一正确拼写的诊断」——
VEL5038 今天在 78 个属性上不兑现这句话。

**这条优先级高于第 173 条**：先让诊断说得出话，
补齐值的那一波才有办法验证自己补对了。

## 记录：Q2 越出 brief 字面的一处扩展，确认

## 记录：它自查捉到了自己写的一个假值

第一版 `outlineStyle` 直接读 `LOOK_BORDER_STYLE_NAMES` 全表，

**这条要记，因为它说明「照抄邻表」也要逐值对语法核一遍** ——
派生优于手抄，但**派生不等于免检**。
