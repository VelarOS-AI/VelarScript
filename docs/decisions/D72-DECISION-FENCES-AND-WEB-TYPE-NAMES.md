## 第 185 条 —— 裁决文档用普通围栏，不用 ```velar

### 我造成的

我在 D70 与 D71 里用了 ```velar 围栏，而 `check:docs` **递归编译整个 `docs/`**。
gate 1 红了 23 行，全部来自这两个文件。

**更值得记的是**：我早先专门查过 D53-D56 有没有 velar 围栏（结果是 0），
**知道这条规则，然后自己破了它。**

### 裁决：裁决文档一律用 ```text

理由不是"避开门禁"，是**裁决文档按其性质就在引用不能编译的东西**：
被否决的语法、被提议但尚未存在的语法、被退役的旧拼写。
D71 的整个论点就是 `computed doubled = count * 2` **今天被拒绝** ——
让门禁去编译它是要求它证明一件本文正在说它不成立的事。

### 不采纳「让门禁跳过 `docs/decisions/`」

那会造出 D56 第 130 条专门要防的形状：**一片没人读的语料**。
今天 `docs/decisions/**` 里的完整例子是被编译的，那是有价值的 ——
坏的只是我写的那几个不该被编译的。

### `rejected` 围栏标注：R2 提议，我限定它的适用范围

R2 建议将来加一个 `rejected` 标注，断言那段代码**必须编译失败**。

**对裁决文档不适用。** 裁决文档记录的是**当时为真的事**，
而语言会变 —— D71 正在推翻 W-124。一条 `rejected` 围栏在推翻落地那天变红，
逼你去改历史，**那是错的**。

**对活文档适用，且有价值。** charter 与简报里有大量「X 被拒绝」的断言，
而 D64 已经证明**散文里的断言没有任何东西钉住**
（D60 第 154 条那条遮蔽陈述就是这么过期的）。
一个 `rejected` 围栏能把「以代码形式写出的拒绝断言」变成受检事实。

**记为提案，限定在 charter/简报/`docs/*.md`，不进 `docs/decisions/`。**
不排期 —— 等有第二个实例再说。

## 第 186 条 —— 用户 `type` 不得静默输给 Web 内建类型名

### 实测（R2 写 `language.md` 时撞上，我确认形状）

```text
type Event:
    kind: string

def describe(event: Event) -> string:
    return event.kind

print(describe({kind: "charge"}))
→ VEL4001 Cannot assign { kind: string } to Event
```

**声明处被接受，每一处使用却解析到 Web 的内建 `Event`。**
作者得到的诊断点名了一个他刚刚亲手声明的类型，而**声明处一声不吭**。

### 这正是 D51 第 109 条那一族，只是没有用到 Web 上

D51 第 109 条把 `Comparable`/`Text`/`Data` 定为**保留类型名**，
用户声明同名时**在声明处拒绝**，理由原文是：

> 在声明处拒绝比在使用处产生歧义好得多

Core 照做了（`const Text = 1` 直接被拒）。
**`packages/web/src/analyzer.ts:107` 的 `webEventTypeNames`
（`Event`、`KeyboardEvent`、`PointerEvent`、`InputEvent`、
`CompositionEvent`、`ClipboardEvent`）没有。**

### 裁决：在声明处拒绝，且**按族派生而不是补这六个**

**只修这六个是错的修法。** Web 还发布着大量内建类型名 ——
Look 的 17 个公开类型（`Length`、`Color`、`Border`…）、
元素类型（`Element`、`InputElement`、`CanvasElement`…）、
`Blob`/`File`/各种事件类型。**每一个都有同样的洞。**

**要求：从 Web 扩展已经登记的类型名表派生这条保护**，
与 D57 第 135 条给 Core 名册做的完全一样（那条也是先补名字、
后来改成从名册派生）。**别再手抄一份名单** —— 这是本仓第十次撞见那一族。

**回归**：逐个内建类型名验证「用户声明同名 → 声明处拒绝」，
且该保护是**派生**的（往类型表加一个名字，保护自动跟上）。

## 记录：R2 的一处规格-现实差

D64 说前言「渲染不可见」。**在 markdown 渲染器里为真，
但 `velar skill` 把简报逐字打到 stdout** —— 前言在那里是一段
给真实读者看的裸 HTML 注释。

**所以简报不适用前言机制**（且它已在 749/750 行）。
R2 因此没有迁移简报的四个片段，**判断正确**。

D64 第 167 条的措辞据此收窄：**前言适用于会被渲染的文档，
不适用于会被逐字打印的文档。**
