## 第 80 条 —— 反引号字符串

### 核心语义（用户已定）

`` `...` `` 与 `"..."` **语义完全相同**：同一种 string 值、同一套能力，
只是定界符不同 —— 反引号串内 `"` 免转义。

### 完整边界（一次设计完，按完整性纪律）

1. **前缀正交**：引号选择（`"` vs `` ` ``）与前缀（`f` / `r` / `rf`）**互相独立**，
   全组合成立：`` f`{x}: {"literal"}` ``、`` r`C:\dir\{"x"}` ``、`` rf`...` ``。
   f 形态的插值**仍是 `{expr}`**（与 f"..." 完全一致）。
2. **转义集**：与 `"..."` 相同（`\\ \n \r \t`），加 `` \` `` 表示字面反引号；
   `"` 在反引号串内**免转义但 `\"` 仍合法**（同一转义集，非新方言）。
   `'` 两种串内都免转义（TXT-I3 的 `\'` 接受修复同批落地）。
3. **`${` 是字面文本**（编排代理决定，可否决）：反引号串**不做** JS 模板串
   插值。不设诊断 —— 生成 JS 代码是正当用例（stdlib 自带 JS 词法器）。
   JS 肌肉记忆陷阱由 AI 简报一行治理：「反引号串不插值；插值是 f 前缀 + `{x}`，
   两种引号皆可」。
4. **不支持裸换行**（与 JS 模板串的第二个分歧）：串内换行 → 既有的教布局串
   诊断。多行归布局串，单行归引号串 —— 分工不变。
5. **替换既有词法教学**：现在的「`` ` `` → 教布局串」拒绝被真实的反引号串
   取代；`'...'` 单引号维持拒绝（教学不变）。
6. **JSX 属性位、Look 内**等一切字符串位置同等合法（同一词法产物）。

### 典章规则：写时随手，读时统一（编排代理决定，可否决）

「哪个方便用哪种」在**书写时**成立；`velar format` 按**确定性规则**归一，
保住「一个明显拼写」与千人千面防线：

| 串内容 | 规范形 |
|---|---|
| 不含 `"` | `"..."`（默认） |
| 含 `"`、不含 `` ` `` | `` `...` `` |
| 两者都含 | 转义更少的那种；平手取 `"..."` |

先例：Python Black 的引号规则同构（默认双引号，除非引入更多转义）。
效果：任何给定内容**恰有一个**规范拼写 —— 规则 3 不破。
