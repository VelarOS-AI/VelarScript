# D113：List 回调携带快照索引（2026-09-05）

## 结论

`List.map`、`flatMap`、`filter`、`find`、`some` 和 `every` 的回调统一接收
`(value, index)`。第二个参数按需声明；只使用值的一参数写法保持不变。索引对应
这些 API 已有的浅快照，而不是回调执行期间可能变化的源 List。

A13 因而可以把无 guard 的双槽构造循环机械改写成双参数 `map` 或 `flatMap`。
带 guard 且投影读取索引的循环不拆成 `filter(...).map(...)`，因为后一个 `map`
看到的是过滤后的新索引；该形状继续保留显式循环。

## 扩展边界

Core 只拥有集合语义与 A13。目标语法通过 `canonicalCollectionProjection` 回答
自己的表达式能否作为稳定投影。Web 仅证明标准原生 JSX：即时求值的属性和子节点
仍需通过 Core 的纯表达式检查，事件箭头只作为尚未执行的函数值；组件、自定义
元素、`ref` 和 `bind:*` 不进入证明。

## 运行时与渲染

六个 List 方法都向回调传递相同的零基快照索引。Web 的 keyed-list 快路径继续只
接收单参数投影，因为按 key 复用的节点在重排后不会重新构造，若其内容读取索引就
会陈旧；双参数 JSX map 使用普通动态区域以保持语义正确。
