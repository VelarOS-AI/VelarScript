## 第 57 条 —— `%` 提升 Core：**撤销**（用户挑战暴露位置依赖语义，记档防复议）

初版裁决采「标量徽章模型」双语境语义（Core 应用 / Look CSS）。用户随即挑战
「某些 css 值可以在外部定义，不会造成混乱和冲突吗」—— 该挑战暴露致命缺陷：

```
const half = 50%
const doubled = half * 2    // 模块顶层（徽章模型）→ 1.0（number）
// 同一表达式在 look 块内（CSS 规则）→ 100%（Percentage）
```

**同一表达式、换位置换结果** —— 正是本次评审九轮追杀的陷阱类别（10%3 跨目标
分叉、可选链位置语义同族）。评审纪律回旋镖命中评审者本人，撤销记录如下：

1. **`%` 不提升 Core**。留在 web —— 那里它只有一套 CSS 规则、位置无关，且
   已有四道防线（规则随类型不随位置、CSS 关键字必须字符串、媒体阈值编译期
   常量、组合重复诊断）。charter §17 的既有位置无关设计是**对的**，成文表扬。
2. Node/Core 侧业务百分数用普通小数 `0.15` —— Lite 服务端零个 `%` 使用点，
   促升无证据。
3. 原想借标量模型抓的 `15% + 0.05` 混算 bug —— **web 今天已在抓**（§17
   同维加减规则，number 非视觉维度）。收益早已存在。
4. D39 第 52 条的 `ms`/`s` 与 `Duration` 提升**不受影响**：Duration 无
   「应用」歧义（同维运算处处一致），`sleep(2s)` 有真实消费者。初版矩阵中
   `2s * 150%` 一行随撤销删除（Duration × Percentage 在 web 维持既有拒绝）。
5. 批次 H 已落地的 `10%3` 百分比教学消息保留（web 语境护栏，与本条无关）。

**教训一句（进评审方法论）**：双语境语义提案必须先过「同一表达式换位置」
测试；位置依赖的运算规则一律视为陷阱候选。

## 第 58 条 —— 单位系统公开化：升格既有扩展钩子（证据门控，挂 D34-A5）

关键事实：单位系统**已经存在** —— web 经扩展协议注册后缀表（LOOK_UNIT_TYPES
→ lexer numericSuffixes）、类型族与运算规则，五个月实战验证。「可扩展单位
系统」不需要发明，需要把这套内部钩子**升格为公开扩展契约**（后缀 → 类型、
同维加减、标量乘除、跨维拒绝）。落地时机：**首个非 web 消费者出现时**
（`velar/game` 的 tile/坐标、金融扩展等），与 D34-A5 领域扩展车道同门控 ——
在那之前只在扩展协议文档中预留章节位。

## 第 59 条 —— 源码级用户自定义单位：明确不做（记档防复议）

`unit km` 式源码声明被否，两个硬理由：

1. **词法架构冲突**：后缀表由扩展在 lexer 启动时喂入；源码声明意味着
   边解析边改词法 —— 上下文敏感词法是坑王。
2. **量纲代数即类型级编程**：`km/h`、`kg·m/s²` 是 F# units of measure 级
   机制，charter 规则 4 明文排除。「不带量纲代数的标签数字」第 58 条的
   扩展路径已覆盖。

## 第 60 条 —— 单位值在普通代码中的边界契约（用户提问驱动，实测全绿后的抛光）

用户问「扩展加的这些标量用在普通函数里不会出问题吗」。六发探针结论：**边界
干净，无静默问题** —— `==` 按值相等（无对象身份陷阱）、普通函数算术照常、
记录字段与 `Type.parse` 都认、有序比较拒绝（原则性：`12px < 1rem` 静态不可
换算）、`sorted()` 要求显式比较器（不可排序即逼显式选择）、f-string 白名单
与 JSON 均正确拒绝。三个抛光项：

1. **VEL4026 对扩展单位值的出口建议失准**（归 I）：消息教 `stringify(value)`
   但 JSON 对 Length 同样拒绝 —— 两个出口断一个。真修法 = D32 当时后置的
   **扩展文本钩子**（Length 插值为 `16px`，文本形良定义），本条即该钩子的
   第一份需求证据；钩子落地前，消息对扩展值改为只教 `print(value)`。
2. 有序比较拒绝消息补原因（归 I）：`…received Length and Length; units may
   be runtime-relative and have no static order`。
3. **边界矩阵成文**（归 C）：charter §17 补「单位值在普通代码中」一段
   （==✓ / 算术✓ / 记录与验证✓ / `<`✗ / sorted 需比较器 / f-string✗ /
   JSON✗），AI 简报一行。
