## Deliberate boundaries

0.6A does not add multiple inheritance, mixins, decorators, method overloads,
operator overloading, metaclasses, user-defined generics, or a parallel
interface/schema system. `type` remains the one data-shape declaration, while
abstract classes own behavioral contracts.

0.6B does not introduce user-defined generics, Python's complete standard
library, JavaScript prototype extensions, global helper pollution, or silent
coercion. Internal polymorphic signatures exist only so ordinary inferred code
keeps precise types.

0.6C does not add SSR, workers, service workers/PWA, WebRTC, WebGPU, directory
handles, or `velar/game`. The next big stage is an external preview and product
feedback loop; repository creation, tags, npm publication, or deployment remain
explicit external mutations requiring separate authority.
