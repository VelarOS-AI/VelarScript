Status: 0.9Z internal explicit-structural-equality gate complete; no publication or external deployment

## 0.9A routed application authoring

| Contract | Evidence |
| --- | --- |
| Expression control flow preserves type facts | Optional identifiers narrow inside the owned true branch of `condition ? then : else`; `not value` narrows the false branch, while emitted presence checks keep `0`, `""`, and `false` distinct from `none` |

## Compatibility versions

The internal toolchain is `0.9.0-dev`. Standard API `0.4`, Web API `0.7`,
project format `2`, production build manifest format `2`, and LSP protocol `1`
define the active clean-break contract. Older project manifests are rejected
instead of migrated. Source that used the unpublished development-only
`List.push(value)` spelling must rename it to `append(value)`; this deliberate
language cleanup happens before a stable release rather than preserving two
mutation names indefinitely.
